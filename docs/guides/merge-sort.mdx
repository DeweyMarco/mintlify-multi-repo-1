---
title: "How merge sort works"
description: "Follow the divide-and-conquer process used by the service."
---

Merge sort recursively divides a list until each partition has at most one item, then merges those partitions in sorted order.

<Steps>
  <Step title="Split">Divide the input at its midpoint into left and right partitions.</Step>
  <Step title="Sort recursively">Apply the same process to each partition.</Step>
  <Step title="Merge">Compare the leading values and append the smaller one to the result.</Step>
</Steps>

## Guarantees

- **Time:** O(n log n) in the best, average, and worst cases.
- **Space:** O(n) auxiliary space for partitions and merged output.
- **Stability:** equal values retain their original relative order.
- **No mutation:** the function returns a new list and leaves the input unchanged.

## Use it directly

```python
from merge_sort_service import merge_sort

result = merge_sort([8, 3, 5, 1, 4])
assert result == [1, 3, 4, 5, 8]
```

The Python function also accepts a `key` callback, matching the common sorting interface:

```python
records = [{"score": 9}, {"score": 3}]
ordered = merge_sort(records, key=lambda record: record["score"])
```
